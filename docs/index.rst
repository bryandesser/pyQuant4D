pyQuant4D documentation
========================

**pyQuant4D** is a Python GUI application for quantitative 4D-STEM data
visualisation and analysis, ported from the original MATLAB
`Quant4D <https://github.com/bryandesser/Quant4D>`_ application developed at
`Monash Imaging Physics <https://www.monash.edu/medicine/ccs/research/monash-imaging-physics>`_.
