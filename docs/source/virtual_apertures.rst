Virtual Apertures
=================

Virtual aperture mode places a circular aperture on the diffraction pattern and
integrates intensity within it at each probe position to form a real-space
image.  Moving or resizing the aperture updates the image in real time.

This is equivalent to placing a virtual detector at an arbitrary position on
the diffraction plane, allowing post-acquisition simulation of any detector
geometry supported by a circular aperture.

.. note::
   This mode is currently under active development.  Full documentation will be
   added when the feature is complete.
