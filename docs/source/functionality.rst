Functionality
=============

`pyQuant4D` has many useful features to allow you to quickly and intuitively
interact with 4D-STEM data.  Because it is built in Python, it can be
installed on any platform that supports Python 3.10+, including Windows,
macOS, and Linux.  The code is GPU-accelerated when a CUDA-capable GPU with
sufficient memory is present (see :ref:`gpu-setup`).
